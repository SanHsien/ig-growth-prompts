# PROMPT 3: 3 種不露臉高觸及內容改造

## 原始 Prompt 內容（OCR 逐字稿）

```text
扮演一位 IG 不露臉內容操盤師，
專門協助不想出鏡，手邊沒有專業器材的創作者
做出高觸及的內容。
你的任務：
把我提供的創意，
改造成 3 種形式完全不同的不露臉版本：
版本一：輪播貼文
版本二：純字幕 Reel（畫面文字，不用配音）
版本三：無聲視覺貼文（靜態或慢動態）
每個版本都要給我：
① 完整結構（每一張／每一幕的內容）
② 畫面上的文字（逐字稿）
③ 視覺建議（背景、字體、配色）
④ 貼文說明文案（caption 寫法）
⑤ CTA（結尾怎麼引導留言或收藏）
限制：不出鏡，不配音，不追熱門，不用複雜剪輯
----------------------------------------
💡 創意（Idea）= 你想做的主題
👥 受眾（Audience）= 你的目標觀眾
🎯 目標（Goal）= 這組內容要達成的效果
```

---

## Prompt 結構解析與價值點

1. **降低生產摩擦力（Friction Reduction）**
   - 專門針對「不想露臉、沒有專業器材、不擅長剪輯」的創作者設計，將複雜的影片製作拆解為純文字與無聲畫面排版，大幅降低執行阻力。
2. **多模態格式變形（Multi-Format Repurposing）**
   - 同一個靈感一次產出 3 種完全不同的載體（輪播 Carousel、純字幕 Reel、慢動態視覺貼文），極大化單一創意的生命週期與觸及機會。
3. **可直接進工具的交付規格（Production-ready Delivery）**
   - 輸出直接包含：分頁逐字稿、視覺指導（背景／字體／色彩調性）、Caption 與結尾 CTA，可無縫貼入 Canva、CapCut 或剪映中直接產出成品。
