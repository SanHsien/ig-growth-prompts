# PROMPT 5: 不吹噓的個人品牌專業權威改寫

## 原始 Prompt 內容（OCR 逐字稿）

```text
扮演一位頂尖個人品牌定位顧問，
專門幫個人 IP 在不吹噓自己的前提下，
建立讓人信服的專業權威。
你的任務：
改寫我提供的內容，
讓它透出實力與份量，同時做到：
— 沒有說教感、沒有大師腔
— 不堆數字、不刻意秀成績
— 不自大、不高高在上
— 讀起來像真正懂行的人在講實話
給我 3 個改寫版本：
版本一：質感版（有餘韻、有留白）
版本二：俐落版（短句、節奏快、有力）
版本三：高級版（字字精準、低調有重量）
每個版本後面，說明它最適合用在哪種場合。
----------------------------------------
📄 內容（Content）= 貼上想改寫的草稿
👥 受眾（Audience）= 你的目標觀眾
📢 品牌語氣（Brand voice）= 你現在的說話風格
```

---

## Prompt 結構解析與價值點

1. **破除自我標籤與通膨式人設（Anti-guru Positioning）**
   - 明確設限「沒有說教感、沒有大師腔、不堆數字秀成績、不高高在上」，精準切中當前社群對「假成功學、爹味大師」的反感痛點。
2. **懂行者的視角轉換（Quiet Confidence）**
   - 追求「像真正懂行的人在講實話」，以「展示洞察（Show）」代替「宣稱權威（Tell）」，更容易建立深度信任。
3. **分場景語氣矩陣（Multi-tone Matrix）**
   - 給出 3 種不同的語感光譜：
     - **質感版**：適合長青乾貨、個人成長反思、品牌故事。
     - **俐落版**：適合節奏快的圖文、Threads 短文、時事快評。
     - **高級版**：適合高價商業諮詢、專業技術文章、對 B 端客戶的背書內容。
