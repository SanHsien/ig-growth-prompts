本專案收錄並深度拆解社群創作者 `@jasonxtsai` 所分享的「Claude IG Prompt 系列」。這套架構將帳號在兩個月內從零拉升至 6 萬追蹤、800 萬次觀看的精華工作流，抽象化為 5 個高度標準化、可隨插即用的 Prompt 模組。

## 5 大核心 Prompt 快速檢索

### 1. 找選題：利基市場防套路與原創點子
- **角色設定**：操盤 IG 超過 10 年成長顧問（帶過 50 個 0 到 10 萬粉帳號）。
- **關鍵指令**：先列 7 個看膩的套路，再給 10 個跳脫套路的原創點子（標註主軸、Hook、格式、新鮮感、收藏理由），最後評選前 3 名。
- **輸入變數**：`利基市場 (Niche)`、`受眾 (Audience)`、`目標 (Goal)`。

### 2. 寫 Hook：15 句 5 種類型開場鉤子
- **角色設定**：專寫爆款開頭的文案操盤手（Hook 平均拉高完播率 40%）。
- **關鍵指令**：針對單一主題輸出 15 句 Hook（懸念、逆向、情緒、數據、內行各 3 句），嚴禁標題黨與 AI 味，每句限 15 字內，評選最強 5 句並說明理由。
- **輸入變數**：`創意 (Idea)`、`受眾 (Audience)`、`語氣 (Tone)`。

### 3. 做不露臉版本：低門檻多格式改編
- **角色設定**：不露臉內容操盤師（專門協助不出鏡、無專業器材創作者）。
- **關鍵指令**：一個主題改編成輪播貼文、純字幕 Reel、無聲視覺貼文。每種版本皆附逐頁結構、畫面文字、視覺色彩建議、Caption 文案與互動 CTA。
- **輸入變數**：`創意 (Idea)`、`受眾 (Audience)`、`目標 (Goal)`。

### 4. 拉留存：完讀率與收藏分享優化
- **角色設定**：留存率優化顧問（擅長把平淡內容改為高收藏、高完讀版本）。
- **關鍵指令**：改寫草稿，刪除軟弱句與廢話，每行結尾設鈎子，口語自然無推銷感，將停留時間、完讀率、收藏數、分享數極大化，並附上改寫理由對照。
- **輸入變數**：`內容 (Content)`、`語氣 (Voice)`、`受眾 (Audience)`。

### 5. 建立權威感：低調有實力的專家定位
- **角色設定**：頂尖個人品牌定位顧問（在不吹噓前提下建立專業信服力）。
- **關鍵指令**：去說教感、去大師腔、不刻意秀成績堆數字，產出質感版、俐落版、高級版 3 種改寫，並註明各版本適合場景。
- **輸入變數**：`內容 (Content)`、`受眾 (Audience)`、`品牌語氣 (Brand voice)`。

## 值得參考的核心思維（Prompt Engineering 視角）

1. **「先破後立」的負面約束（Negative Constraint First）**
   - 多數 Prompt 直接問「給我 10 個點子」，模型容易產出全網雷同的平庸內容。Prompt 1 先要求「列出 7 種看膩的套路」，讓模型在思考前建立過濾邊界，大幅提升原創度。
2. **多維度分類矩陣（Categorical Taxonomy）**
   - Prompt 2 將 Hook 嚴格細分成 5 種類型（懸念／逆向／情緒／數據／內行），避免模型只會產出一種調性的句子，給創作者豐富的 A/B 測試空間。
3. **消除模型感與爹味（Anti-AI & Anti-Guru Tone）**
   - 明確加入「要像真人在講話，沒有 AI 味」、「沒有說教感、沒有大師腔、不堆數字秀成績」，精準避開大語言模型容易出現的空泛辭藻與好為人師的口氣。
4. **輸出即產品（Production-Ready Deliverables）**
   - 包含畫面逐字稿、視覺搭配建議、Caption、CTA、排名前三理由與改寫對照，所有輸出可直接丟進 Canva、剪映或排程工具中發布。

## 我可以仿照做什麼（實踐行動指南）

### 1. 打造技術／知識型個人的「不露臉」自媒體
- **工程師／技術人痛點**：不想露臉、沒時間拍片、討厭浮誇行銷。
- **具體實踐**：
  - 挑選平日遇到的技術坑、架構決策或開發心得作為素材。
  - 套用 Prompt 3 生成「輪播圖卡（Code/Architecture Slide）」或「純文字短片」。
  - 透過 Prompt 5 修飾成低調懂行的語氣，在 Threads、IG、LinkedIn 建立專業形象。

### 2. 開發自動化內容生成 CLI 工具
- 建立一個名為 `content-cli` 的 Python/Node.js 小工具：
  - 傳入一個主題關鍵字或一段未整理的 Note。
  - 自動連鎖呼叫 Prompt 1 ~ Prompt 5。
  - 最終輸出 Markdown 貼文檔案，並透過 Playwright / Satori 自動生成社群輪播圖。

### 3. 將框架移植至其他平台與領域
- **Threads / X (Twitter)**：利用 Prompt 2 的 15 字 Hook 搭配 Prompt 4 的滑梯效應，寫出高轉發、高討論的串文（Threads）。
- **技術部落格 / 電子報（Newsletter）**：利用 Prompt 1 避開過度飽和的教學題目，並用 Prompt 5 的質感版／高級版撰寫長文。
- **商業顧問／B2B 企劃提案**：套用 Prompt 5 的去油膩風格，讓商業簡報與提案在不浮誇的狀態下展現實力。
